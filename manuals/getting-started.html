MAIHomeCenter Admin Manual

Getting Started

Overview of the admin panel and common workflows

Logging In

Open the admin panel in your browser. You will see the login screen with the MAIHomeCenter logo.

  1. Enter your Username
  2. Enter your Password
  3. Click Sign In

After logging in, you will see the Notifications page.

Navigation

The navigation bar at the top contains four sections:

SectionDescription
NotificationsSend push notifications to tenants
SurveysCreate, send, and review questionnaires
Alert RulesSet up automatic alerts based on sensor data
HousesManage tenant installations and view dashboards

On the right side of the navigation bar:

  • Your name and organization are displayed
  • NL / EN — Switch between Dutch and English
  • Sun/Moon icon — Toggle between light and dark theme
  • Logout — Sign out of the admin panel

Language

The entire admin interface is available in Dutch (NL) and English (EN). Click the language toggle in the navigation bar to switch. Your preference is saved and remembered for next time.

Theme

Click the sun/moon icon to switch between light and dark mode. Your preference is saved automatically.

Typical Workflows

Monitor your houses

  1. Go to Houses
  2. Use the alert filters to see which houses had issues today or this week
  3. Click Dashboard on any house to see detailed sensor charts

Send a survey after an alert

  1. Go to Surveys and click Send on the survey you want to use
  2. Use the alert rule shortcuts to quickly select houses that triggered a specific alert
  3. Click Send

Set up automatic survey sending

  1. Go to Surveys and click Trigger on the survey
  2. Add sensor conditions (e.g., Temperature above 26)
  3. Set a sustained duration if you want to avoid false positives
  4. Enable the trigger and save

Create an alert rule

  1. Go to Alert Rules and click + New Rule
  2. Name the rule and set conditions
  3. Configure the notification message (use {room} and {value} for dynamic content)
  4. Save and activate
